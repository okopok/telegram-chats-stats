# Документация chatStats

Здесь живёт подробная документация проекта. `AGENTS.md` в корне — краткая шпаргалка со ссылками на эти разделы; подробности держатся только в одном месте — в `docs/`.

## Разделы

| Раздел | О чём |
|---|---|
| [Архитектура](architecture.md) | Пайплайн потока данных, слои и ключевые классы, кэш сообщений, парсер экспорта, сущности. |
| [Установка и использование](usage.md) | Требования, установка, команда `generate`: аргументы, опции, примеры (русский). |
| [Installation & usage](usage.en.md) | То же на английском (English version of the above). |
| [Разработка](development.md) | Как добавить новую статистику (3 шага), шаблоны Twig, конфиги, конвенции кода. |

См. также [README.md](../README.md) (англ.) и [README.ru.md](../README.ru.md) (рус.) — быстрый старт инструмента.

## Правило документации

**Любое изменение проекта (новый обработчик, изменение пайплайна, CLI, конфигов или шаблонов) сопровождается обновлением соответствующих разделов этой документации.** Документация — часть изменения, а не отдельная задача: без обновления `docs/` изменение не считается завершённым.

## Исторические артефакты

`docs/superpowers/` — спека и план редизайна проекта (2026-09-29). Это исторические документы процесса разработки, а не актуальное описание системы; при расхождении с разделами выше актуальны разделы выше.
